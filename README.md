# YSERV

## O que é o YSERV?
O YSERV é um aplicativo que conecta clientes a prestadores de serviço de forma prática, segura e confiável. A plataforma permite que usuários encontrem profissionais para diferentes tipos de serviços, visualizem portfólios de trabalhos realizados, comparem avaliações e deixem feedbacks após a contratação.

Além disso, o sistema busca aumentar a confiança entre clientes e profissionais por meio de um processo de verificação de prestadores, garantindo maior segurança nas contratações. O objetivo do YSERV é facilitar a busca por serviços e oferecer um ambiente transparente onde clientes possam tomar decisões mais informadas ao contratar um profissional.
