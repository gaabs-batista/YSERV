
# Projeto de Interface

Visão geral da interação do usuário por meio das telas do sistema, incluindo a definição da identidade visual e a prototipagem no Figma, com um protótipo interativo que representa as principais funcionalidades da plataforma (wireframes).

## Identidade Visual 

Toda a identidade visual foi desenvolvida no figma, com referencias de criação do site [Ponto Design](https://pontodesign.com.br)
