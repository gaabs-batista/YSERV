# 🚀 YSERV - MVP

Este projeto é um **MVP (Minimum Viable Product)** de um aplicativo mobile desenvolvido com **React Native (Expo)** e **Firebase**.

---

## 📱 Sobre o projeto

O YSERV é um aplicativo em desenvolvimento que tem como objetivo conectar usuários a serviços de forma prática e intuitiva.

Nesta versão inicial, o foco está na validação da base do sistema e da experiência do usuário.

---

## ⚙️ Tecnologias

- React Native (Expo)
- Firebase
- JavaScript

---

## 📲 Acesso ao app

O aplicativo pode ser executado via **Expo Go**.

👉 [Clique aqui para acessar o projeto](https://snack.expo.dev/@gabriellerrr/cc8b85)

---

## 🎯 Objetivo

Este MVP tem como finalidade validar a estrutura inicial do aplicativo e servir como base para as próximas etapas do projeto.
